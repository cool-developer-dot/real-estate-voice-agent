==================================================
5. SIGNATURE INTERACTION — "STAMP"
==================================================

This is the most important visual interaction.

When a field transitions:

EMPTY → FILLED

the newly populated value must visually "stamp" into the registry document.

Example:

Before:

BUDGET        —

After:

BUDGET        20,000,000 ✓

The filled value should briefly:

- start slightly scaled up
- fade in
- settle into its normal position
- feel like a document field being stamped/registered

Use a short, polished animation.

Target behavior:

0ms:
opacity: 0
transform: scale(1.05)

~150ms:
opacity: 1
transform: scale(0.99)

~220ms:
opacity: 1
transform: scale(1)

Use a professional easing curve such as:

cubic-bezier(.2,.8,.2,1)

The animation must be subtle.

NO flashy bounce.
NO excessive glow.
NO large movement.
NO screen-wide animation.

The effect should communicate:

"SPEECH → STRUCTURED DATA"

==================================================
6. IMPORTANT — ANIMATION MUST TRIGGER ON TRANSITION
==================================================

Do NOT animate the field continuously.

The animation should happen only when a field changes from:

null / empty / undefined

to:

a real value.

If the component re-renders while the value remains unchanged, do NOT replay the animation.

Implement this robustly using React state/ref logic or an appropriate reusable mechanism.

For example, conceptually:

empty → filled = animate

filled → filled = no animation

empty → empty = no animation

Do not rely only on initial page-load animation.
