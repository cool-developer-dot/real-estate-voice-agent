2. THE MOST IMPORTANT PRINCIPLE
==================================================

DO NOT MAKE EVERYTHING GLASS.

This is critical.

Create a hierarchy of materials.

Use approximately:

LEVEL 0
Background

LEVEL 1
Primary application surfaces

LEVEL 2
Glass cards

LEVEL 3
Floating controls

LEVEL 4
Dropdowns / modals / overlays

LEVEL 5
Focused / active elements

Not every element should have the same blur, opacity, border, and shadow.

Different depth = different material treatment.

==================================================
3. BACKGROUND
==================================================

Keep the EXISTING background colors.

Improve only the atmospheric depth.

Use existing gradients where already present.

If additional atmospheric lighting is needed:

- derive it from existing colors
- keep opacity extremely low
- keep it static or extremely slow
- never overpower content

The background should create enough visual contrast for the glass surfaces to be visible.

Do not add giant colorful blobs.

Do not add excessive animated gradients.

==================================================
4. GLASS MATERIAL
==================================================

Create a reusable glass surface system.

Conceptually:

.glass-surface

should combine:

- translucent background
- backdrop blur
- subtle saturation
- fine border
- soft shadow
- optional inner highlight

Example direction:

background:
rgba(255,255,255,0.55–0.80)

backdrop-filter:
blur(20px–32px) saturate(110%–125%)

border:
1px solid rgba(255,255,255,0.45–0.70)

shadow:
large, soft, low-opacity

IMPORTANT:

Do not blindly use these exact values everywhere.

Tune them against the EXISTING color scheme.

The surface must remain readable.

==================================================
5. GLASS DEPTH
==================================================

Create at least three glass depths.

LIGHT GLASS:

For:
- cards
- panels
- secondary surfaces

MEDIUM GLASS:

For:
- header
- sidebar
- major dashboard containers

STRONG GLASS:

For:
- dropdowns
- notifications
- popovers
- modals

Strong glass must have enough opacity that content underneath does not become confusing.
